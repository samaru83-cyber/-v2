# 분양 고객관리 (PWA)

분양팀 고객관리 앱. 팀장은 PC에서, 직원은 휴대폰에서 같은 앱을 씁니다.
서버 없이 각 기기 브라우저 안(IndexedDB)에만 저장하고, 팀장↔직원은 **파일을 카톡으로 주고받아** 맞춥니다.
앱스토어 없이 링크로 배포하고, 설치하면 오프라인에서도 실행됩니다.

## 팀 운영 방법 (팀장 PC ↔ 직원 휴대폰)

```
팀장 PC (원본)                               직원 휴대폰
───────────────                              ───────────────
① 손님 등록 / 엑셀(CSV) 명단 가져오기
② 담당 직원 지정 (고객 표에서 체크 → 일괄 배정)
③ 파일 주고받기 → [배정 파일 만들기] ──카톡──▶ 설정·첫화면에서 [배정 파일 불러오기]
                                              → 내 손님만 들어옴, 관리·문자·일정 입력
⑤ 보고 파일을 화면에 끌어다 놓기   ◀──카톡── ④ [보고 파일 보내기] (하루 1번, 퇴근 전)
→ 팀 현황 대시보드에 반영
```

**팀장 대시보드(팀 현황)에서 보이는 것** (노트북 한 화면 기준)
- 맨 위 숫자 4개: 오늘 방문 · 오늘 입금(금액) · 입금 지연(금액) · 이번 달 실적(계약 · 방문 · 신규 · 입금 합계)
- **오늘 시간표**: 오늘 방문·입금·계약 일정을 시간순 한 줄씩, 담당 직원과 [방문 확인]/[입금 확인] · 아래에 내일 일정
- **확인 필요**: 늦어진 입금·계약(빨간색, 바로 [입금 확인]), 오늘 보고 전 직원, 서류 미비, 관리 기한 지남, 담당 없는 손님 (눌러서 펼침)
- 이번 주 계약·입금: 7일 안에 다가오는 일정과 입금 예정 합계
- 직원별 현황(접혀 있음): 담당 수 · 이번 달 계약 · 오늘 방문 · 입금 지연 · 기한 지남 · 서류 미비 · **최근 보고 시각**
- 오른쪽 위 직원 선택으로 한 사람 것만 볼 수 있음

**콜 배분 (메뉴: 팀장 '콜 배분' / 직원 '받은 콜')**
- 팀장: 콜 종류(회사콜·광고콜 등) 고르고 → 번호·이름·메모 입력 → 담당 직원 선택 → [콜 주기]
  - 담당 버튼에 직원별 오늘 받은 콜 수가 보이고, 가장 적은 직원이 미리 선택됩니다(바꿀 수 있음)
  - 같은 번호로 이미 준 콜이나 이미 등록된 고객이 있으면 바로 경고
- 직원: 받은 콜에서 [전화] → [결과 입력] (부재 · 통화완료 · 방문예약 · 방문 · 계약 · 무효) → 필요하면 [고객으로 등록]
- 배정 파일에 그 직원의 콜이 같이 가고, 보고 파일로 결과가 돌아옵니다
- 팀장 화면: 하루 넘게 결과 없는 콜, 직원별·콜 종류별 성과(받은 콜 · 미처리 · 통화 · 방문 · 계약 · 방문율 · 계약율), 콜 목록
- 콜에서 등록한 고객 카드에 방문 확인·계약서 작성을 체크하면 콜 성과에도 자동으로 잡힙니다
- 콜 종류는 설정 → 콜 종류에서 추가·삭제

**합치기 규칙** (같은 손님을 양쪽에서 고쳤을 때)
- 기본 정보: 더 최근에 고친 쪽이 남음 · 상담 히스토리: 양쪽 모두 합쳐짐
- 계약 일정·서류: 항목별로 최근 것이 남음 (팀장이 한 입금 확인이 직원 파일 때문에 지워지지 않음)
- 담당 직원: 항상 팀장 결정이 우선 · 재배정된 손님은 다음 배정 파일을 받을 때 이전 직원 폰에서 빠짐
- 직원은 팀장이 배정한 손님을 삭제할 수 없음

**엑셀 명단 가져오기**: 첫 줄에 `이름, 연락처`(필수)와 `현장, 관심타입, 동호수, 등급, 유입경로, 최초상담일, 다음관리일, 방문일, 방문시간, 메모, 담당` 열.
엑셀 기본 CSV(한글 윈도우)와 CSV UTF-8 모두 읽습니다. 이미 있는 번호는 건너뜁니다.

⚠️ 배정·보고 파일에는 손님 개인정보가 들어 있습니다. 카톡 등으로 보낸 뒤에는 대화방에서 파일을 지우고, 팀 단톡방이 아닌 1:1로 보내세요.

## 폴더 구조

```
bunyang-crm/
├─ index.html              앱 틀 (아이콘, 보안 정책)
├─ manifest.webmanifest    설치 정보
├─ sw.js                   오프라인 캐시 (수정 배포 시 VERSION 올리기)
├─ css/app.css             기본 디자인 · 다크모드
├─ css/team.css            팀 화면 · PC 레이아웃(1024px 이상 사이드바)
├─ icons/                  앱 아이콘
└─ js/
   ├─ app.js               시작 · 화면 전환 · 모드별 메뉴
   ├─ db.js                IndexedDB 저장소 · 설정
   ├─ store.js             고객/히스토리/계약 일정/서류/템플릿
   ├─ team.js              배정·보고 파일, 합치기, CSV 가져오기
   ├─ utils.js             날짜 · D-day · 전화번호 · 템플릿 변수
   ├─ ui.js                카드 · 시트 · 관리 완료 · 현장 탭
   ├─ seed.js              샘플 데이터 · 기본 템플릿 9종
   └─ views/               setup · team · sync · home · customers · detail · form · sms · calendar · settings
```

## 배포 (둘 중 하나, 모두 무료 · HTTPS 자동)

PWA 설치와 오프라인 기능은 **HTTPS 주소**에서만 동작합니다. 아래 두 방법 모두 HTTPS를 자동으로 줍니다.

### 방법 A. Netlify Drop (가장 쉬움, 2분)
1. PC 브라우저에서 https://app.netlify.com/drop 접속 → 무료 가입(이메일/구글)
2. `bunyang-crm` 폴더를 통째로 화면에 끌어다 놓기
3. `https://임의이름.netlify.app` 주소가 생김 → **Site settings → Change site name**에서 원하는 이름으로 변경
4. 수정본 배포: 사이트의 **Deploys** 탭에 폴더를 다시 끌어다 놓기

### 방법 B. GitHub Pages
1. https://github.com 가입 → 오른쪽 위 **+ → New repository** → 이름 예: `bunyang-crm` → Public → Create
2. **uploading an existing file** 클릭 → `bunyang-crm` 폴더 *안의* 파일·폴더 전부 끌어다 놓기 → Commit changes
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://내아이디.github.io/bunyang-crm/` 주소로 접속
5. 수정본 배포: 바뀐 파일을 같은 방식으로 다시 업로드

### 수정본을 배포할 때
- `sw.js` 맨 위 `VERSION = 'v1'`을 `'v2'`, `'v3'`… 로 올린 뒤 업로드하세요.
- 휴대폰에서는 앱을 **한 번 열었다 닫고 다시 열면** 새 버전이 적용됩니다.

## 휴대폰에 설치

> ⚠️ **먼저 설치하고, 그 다음부터 고객을 입력하세요.**
> 특히 iPhone은 Safari에서 쓰던 데이터와 홈 화면 앱의 데이터가 **따로 저장**됩니다.
> Safari에서 입력한 고객은 홈 화면 앱에 보이지 않습니다.

### iPhone (Safari 필수)
1. **Safari**로 배포 주소 접속 (카톡 안 브라우저·크롬 X)
2. 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**
3. 이제 홈 화면의 **고객관리** 아이콘으로만 실행

### Android (Chrome)
1. **Chrome**으로 배포 주소 접속
2. 주소창 아래 **앱 설치** 안내가 뜨면 누르기
   (안 뜨면 **⋮ 메뉴 → 홈 화면에 추가** 또는 **앱 설치**, 또는 앱의 설정 탭 → **홈 화면에 설치**)

### 처음 실행 후 할 일
**팀장 (PC 크롬/엣지)**
1. 첫 화면에서 **팀장** 선택 → 내 이름, 직원 이름 입력
2. **설정**: 소속 현장 · 견본주택 주소, 등급별 관리주기 입력 (배정 파일에 실려 직원 폰에도 자동 적용)
3. 미리 보려면 **설정 → 샘플 고객 넣기** (샘플 직원 3명 포함), 다 봤으면 **지우기**
4. PC에서도 주소창 오른쪽 **설치 아이콘(⊕)** 을 누르면 바탕화면 앱처럼 씁니다

**직원 (휴대폰)**
1. 앱 설치 → 첫 화면에서 **직원** 선택 → **배정 파일 불러오기** (카톡으로 받은 파일)
2. 하루 일과 끝에 홈의 **보고 보내기** → 카카오톡 → 팀장님

## 개인정보 · 백업

- 고객 정보는 **그 휴대폰 안에만** 저장되고 외부로 전송되지 않습니다.
  (index.html의 보안 정책으로 외부 서버 연결을 막아 두었습니다.)
- 배포 주소를 다른 사람이 열어도 **빈 앱**이 보일 뿐, 내 고객 정보는 보이지 않습니다.
- 대신 휴대폰 분실·초기화·앱 삭제 시 데이터도 사라지니 **설정 → 전체 백업(JSON)** 을 주기적으로 해서
  카톡 나에게 보내기, 구글 드라이브, iCloud 등에 보관하세요. (7일 넘으면 설정 화면에 경고 표시)
- 휴대폰을 바꿀 때: 기존 폰에서 백업 → 새 폰에 앱 설치 → **설정 → 백업 파일 불러오기**
- 배포 주소가 바뀌면 데이터가 따라오지 않으니, 주소를 바꾸기 전에도 백업 → 불러오기를 하세요.
- 엑셀용 CSV는 열람·보고용입니다. 복원은 JSON 백업으로만 됩니다.

## 알아둘 점

- **문자 발송 기록**: 문자앱에서 실제로 보냈는지는 앱이 알 수 없어서 [복사] 또는 [문자앱 열기]를 누른 시점에 기록합니다.
- **알림**: 서버 없이는 정해진 시각 푸시 알림을 보낼 수 없어서, 앱을 열면 상단 배너와 홈 탭 숫자로 오늘 관리 고객 수를 알려줍니다.
  (Android 등 지원 기기에서는 앱 아이콘에도 숫자 배지가 표시됩니다.)
- **iPhone 문자앱**: 일부 iOS 버전에서는 본문이 자동 입력되지 않을 수 있어 [복사] 버튼을 함께 제공합니다.

## PC에서 미리보기 (개발용)

PowerShell에서:

```powershell
powershell -ExecutionPolicy Bypass -File ..\.claude\serve.ps1 -Port 8850
```

브라우저에서 http://localhost:8850 접속 (개발자도구에서 모바일 화면으로 보기).
